# Agent 文档

面向自动化 Agent（AI 编程助手、CI 机器人）的规则与速查。分派涉及代码的任务时，把本目录下相关文档附进任务说明。

| 文档 | 适用范围 |
|---|---|
| [codebase.md](./codebase.md) | 所有涉及代码修改的任务：项目地图、硬规则、任务步骤、验证方法 |
| [theming.md](./theming.md) | 涉及颜色的任务：配色硬规则、历史错误模式、检查清单 |

## 使用方式

- 通用代码任务：附带 `codebase.md`。
- 涉及颜色/主题的任务：同时附带 `codebase.md` 与 `theming.md`。
- 涉及 API 的任务：另附 `../api.md`。
- 文档类任务：遵循 `../README.md` 的总目录结构与文风要求（不使用「你」、不用 AI 式套话、以规则和操作直接叙述）。

## 通用约束

- 只改任务要求的范围；不顺手重构、不跑全量格式化。
- 跳过全量测试与全项目 lint（任务指定的除外），验证用任务范围内的最小命令。
- 修改共享组件/API 前用引用查找确认调用方。
- 完成前必须给出可观察的验证结果（浏览器实测、类型检查、lint 输出），不凭推断声称完成。
